# 🗂️ 주식 전망 분석 웹사이트 — 기능 명세서

> 기획자 에이전트 산출물 | 아키텍처: Next.js Frontend Only

---

## 1. 타겟 사용자 페르소나

| 구분 | 내용 |
|------|------|
| **주 타겟** | MZ세대~40대 국내 개인 투자자 |
| **투자 경험** | 입문~중급 (HTS보다 직관적인 UX 선호) |
| **사용 환경** | PC 메인 + 모바일 보조 |
| **핵심 니즈** | "이 종목 지금 사도 될까?" → AI 기반 빠른 판단 지원 |
| **Pain Point** | 정보 파편화, 전문 용어 진입장벽, 뉴스 감성 해석의 어려움 |

## 2. 기능 명세서 (MoSCoW)

### ✅ Must Have — MVP 필수

| 기능 ID | 기능명 | 설명 | 필요 데이터 |
|---------|--------|------|------------|
| M-01 | 종목 검색 | 종목명/티커로 국내외 주식 검색, 자동완성 | 종목 메타데이터 (심볼, 이름, 거래소) |
| M-02 | 현재가 조회 | 현재가, 전일 대비 등락률, 거래량 | 실시간(지연) 시세 |
| M-03 | 캔들스틱 차트 | 일/주/월봉 OHLCV 차트, 기간 선택 | OHLCV 히스토리 |
| M-04 | 이동평균선 | MA 5/20/60/120일선 차트 오버레이 | 종가 히스토리 |
| M-05 | RSI 지표 | RSI(14) 서브 차트, 과매수/과매도 구간 표시 | 종가 히스토리 |
| M-06 | MACD 지표 | MACD / Signal / Histogram 서브 차트 | 종가 히스토리 |
| M-07 | AI 전망 분석 | Claude API로 종목 전망 요약, 투자 포인트, 리스크 분석 | 시세, 지표, 최신 뉴스 컨텍스트 |
| M-08 | 뉴스 목록 | 종목 관련 최신 뉴스 리스트 | 뉴스 헤드라인, 출처, 시간 |
| M-09 | 뉴스 감성분석 | 개별 뉴스 긍정/부정/중립 점수 (Claude API) | 뉴스 본문 텍스트 |
| M-10 | 관심종목 저장 | 관심종목 추가/삭제, 로컬스토리지 영속화 | 없음 (클라이언트 전용) |

### 🔶 Should Have — 2차 스프린트

| 기능 ID | 기능명 | 설명 | 필요 데이터 |
|---------|--------|------|------------|
| S-01 | 종목 비교 | 2~3개 종목 수익률 차트 비교, 지표 비교표 | 복수 종목 OHLCV |
| S-02 | 재무 요약 | PER, PBR, EPS, 시가총액 등 밸류에이션 카드 | 재무 데이터 |
| S-03 | 52주 최고/최저 | 가격 레인지 바 시각화 | 52주 히스토리 |
| S-04 | 섹터/업종 필터 | 대시보드 관심종목 섹터별 그룹핑 | 종목 섹터 메타데이터 |
| S-05 | AI 분석 히스토리 | 이전 AI 분석 결과 날짜별 로컬 저장 | 없음 (클라이언트 전용) |

### 🔷 Could Have — 여유 시 추가

| 기능 ID | 기능명 | 설명 |
|---------|--------|------|
| C-01 | 볼린저 밴드 | 차트 오버레이 보조 지표 |
| C-02 | 시장 지수 위젯 | 코스피/코스닥/S&P500/나스닥 현황 |
| C-03 | 종목 알림 설정 | 목표가 도달 시 브라우저 Push 알림 |
| C-04 | 다크/라이트 테마 토글 | 사용자 테마 선택 |
| C-05 | 포트폴리오 수익률 계산 | 매수가 입력 → 현재 손익 계산 |

### ❌ Won't Have — 이번 MVP 제외

## 3. 페이지 구조도 (IA)

```
/ (루트)
├── 홈 — 대시보드 (/)
│   ├── 시장 현황 위젯 (코스피, 코스닥, S&P500)
│   ├── 관심종목 리스트 (등락률, 미니차트)
│   └── 최근 조회 종목
│
├── 종목 검색 (/search)
│   ├── 실시간 자동완성 검색창
│   └── 검색 결과 리스트 (종목명, 티커, 거래소, 현재가)
│
├── 종목 상세 (/stock/[symbol])
│   ├── 헤더: 종목명 + 현재가 + 등락률 + 관심종목 버튼
│   ├── 탭 1: 차트
│   │   ├── 캔들스틱 메인 차트 (기간 선택: 1D/1W/1M/3M/1Y)
│   │   ├── 이동평균선 토글 (MA5/20/60/120)
│   │   └── 서브 차트 탭: RSI / MACD 선택
│   ├── 탭 2: AI 전망 분석
│   │   ├── 종합 전망 요약 (상승/중립/하락 판단 + 신뢰도)
│   │   ├── 투자 포인트 (Bullish / Bearish)
│   │   ├── 기술적 분석 요약
│   │   └── AI 분석 재생성 버튼
│   ├── 탭 3: 뉴스
│   │   └── 뉴스 카드 목록 (헤드라인 + 감성점수 + 출처 + 시간)
│   └── 탭 4: 재무 (S-02, 2차)
│       └── 밸류에이션 지표 카드
│
├── 종목 비교 (/compare)          ← S-01 (2차)
│   ├── 종목 추가 검색창 (최대 3개)
│   ├── 수익률 비교 라인 차트
│   └── 지표 비교 테이블 (PER, PBR, RSI 등)
│
└── (전역 컴포넌트)
    ├── Header: 로고 + 검색창 + 관심종목 아이콘
    └── 관심종목 사이드 패널 (슬라이드 인)
```

## 5. 외부 API 요구사항

### 주식 데이터
| API | 용도 | 무료 한도 | 비고 |
|-----|------|----------|------|
| **Yahoo Finance** (via RapidAPI) | 실시간(지연) 시세, 종목 검색, OHLCV, 시장 지수 | 500회/월 (무료 플랜) | 국내/해외 종목 모두 지원 |
| **Alpha Vantage** | RSI, MACD, 이동평균 기술적 지표 | 25회/일, 500회/월 | 지표 계산값 직접 제공 |

### 뉴스 데이터
| API | 용도 | 무료 한도 | 비고 |
|-----|------|----------|------|
| **Financial Modeling Prep (FMP)** | 종목별 관련 뉴스 | 250회/일 | 영문 뉴스 중심 |

### AI 분석
| API | 용도 | 과금 방식 | 비고 |
|-----|------|----------|------|
| **Anthropic Claude API** | 종목 전망 분석, 뉴스 감성분석 | 토큰 사용량 과금 | claude-sonnet 추천 (비용/성능 균형) |

### API 키 보안 전략 (Next.js Only 환경)
```
클라이언트 컴포넌트
      ↓  fetch('/api/stock/quote')
Next.js API Routes (서버사이드)   ← API 키 여기서만 사용
      ↓  실제 외부 API 호출
Yahoo Finance / Alpha Vantage / FMP / Claude API
```
> ⚠️ `NEXT_PUBLIC_` 접두사 없는 환경변수만 사용 → 클라이언트 번들에 키 포함 방지

## 6. MVP 범위 및 개발 우선순위

```
Phase 1 — MVP (2~3주)
  M-01 종목 검색
  M-02 현재가 조회
  M-03 캔들스틱 차트
  M-04 이동평균선
  M-07 AI 전망 분석
  M-08 뉴스 목록
  M-10 관심종목 저장

Phase 2 — 기술적 분석 완성 (1~2주)
  M-05 RSI
  M-06 MACD
  M-09 뉴스 감성분석

Phase 3 — 확장 기능 (2주+)
  S-01 종목 비교
  S-02 재무 요약
  S-03~S-05 기타 Should Have
```

## 7. Designer 에이전트 인계 사항

- 다크모드 우선, Bloomberg / TradingView 스타일 레퍼런스
- 캔들스틱 차트 + RSI/MACD 서브 차트 레이아웃이 핵심 화면
- AI 분석 결과는 "로딩 중 → 스트리밍 텍스트" UX가 중요 (Claude API 스트리밍 대응)
- 모바일에서 탭 내비게이션으로 차트 / AI / 뉴스 전환 가능해야 함
